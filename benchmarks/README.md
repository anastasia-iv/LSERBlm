# Сербский бенчмарк: языковая демонстрация v2

- Активный набор ноутбука — `serbian_25_v2.jsonl`: **25 заданий**. Первые пять вводов
  совпадают с прежними, 13 сложных заданий упрощены. Оставлены короткие описания,
  простые факты, вопросы по одному действию и небольшие бытовые истории.
- Эксперименты 1–9 показывают пять общих продолжений. Финальная SFT 3e-5 — все 25.
- CPU/FP32, seed=42, top_k=40. Общие пять: 32 новых токена. Ещё 20: до 64 токенов.
  Продолжения — sampling temperature=0.8; вопросы — greedy в SFT-шаблоне.
- Задания зафиксированы до нового прогона; ответы не отбираются по удачности.
  Проверка точных подстрок вопросов/контекстов SFT-train не нашла совпадений.
  Это не проверка смысловых парафразов и не независимый скрытый test.
- Версия/хеши/протокол — `serbian_25_v2_manifest.json`.

## Результаты и воспроизведение

- `sft_results/deep_continue_B_sft_lr3e5_v2_cpu.json`: свежий полный CPU-инференс v2.
- `sft_v2_reviews_ru.json`: ручные переводы и комментарии, связанные с SHA256 ответов.
- `serbian_llm.ipynb` в корне проекта: прямые вызовы модели, сохранённый вывод и таблицы.
  При повторном выполнении ячеек ответы генерируются заново, переводы нужно сверять.
- `sft_comparison.json`: неизменные результаты SFT-validation/test и LM-validation;
  выбор финального checkpoint выполнен по SFT-validation, а не по новому бенчмарку.

Пять общих примеров через CLI:

```bash
PYTHONPATH=src python -m serbian_llm benchmark \
  --checkpoint runs/deep_continue_B_sft_lr3e5/best.pt \
  --examples benchmarks/serbian_25_v2.jsonl --limit 5 \
  --output benchmarks/v2_five_repeat.json --question-format sft \
  --max-new-tokens 32 --device cpu --precision fp32
```

Полный протокол с разными лимитами для общей пятёрки и остальных заданий
воспроизводится последней кодовой ячейкой ноутбука.

## Проверка пересечений с обучением

Полные вводы v2 проверены как точные подстроки после NFC, приведения регистра
и пробелов. В SFT-train проверены вопросы, контексты и ответы — совпадений нет.
В исходном pretraining-train совпадений нет; в расширенном найдены №21 в одном
документе и №22 в пяти документах. Эти два коротких продолжения уже встречались
модели, поэтому весь набор нельзя называть полностью невиданным test.
Смысловые парафразы и близкие формулировки эта проверка не исключает.
Отчёт: `serbian_25_v2_train_overlap.json`.
